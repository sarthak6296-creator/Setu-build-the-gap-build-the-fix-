## Project description
OpportunityKit helps students find out if they qualify for an internship, scholarship or competition. The student pastes the opportunity text, and clear visible rules turn it into a checklist. The checklist is compared with a simple student profile. Each requirement gets MATCH, MISMATCH or MISSING INFO with a plain reason and a fix, followed by a summary and next steps. Unknown answers are never treated as failures.

## Key features
- One checklist format for internships, scholarships and competitions
- Rule-based detection of year, branch, CGPA or marks, skills, documents, links, weeks, income, team size and deadline
- Detected phrases are highlighted in the pasted text; every field can be edited
- Three statuses with a short reason and a fix for each item
- Readiness bar, summary and ordered next steps
- Clear error messages, mobile friendly, dark mode
- Works fully in the browser: no server, no API keys

## Example result
Sample internship vs 2nd-year CSE student: 3 matches, 1 mismatch (JavaScript not listed), 2 missing (GitHub link, availability). Not ready to apply yet.

## Monetization
Free plan for students; Student Plus with paid extras (reminders, saved history, curated lists); college license for placement cells (batch dashboard). Very low running cost because rules run in the browser. Pilot prices are assumptions to test with real users.

## How it works
Paste text, Build checklist, fill profile, Check my fit. Rules are simple comparisons (for example CGPA at or above the cut-off), so every result is explainable.
